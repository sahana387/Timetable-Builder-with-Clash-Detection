# Timetable Builder with Clash Detection — Team Kit

This folder contains the planning and coordination documents for a four-person full-stack project.

## Files
- `PRD.md` — product scope, requirements, clash rules, and acceptance criteria.
- `AGENTS.md` — coding rules, ownership boundaries, and Git contribution expectations.
- `API_CONTRACT.md` — shared REST/JSON payloads, endpoints, errors, and validation.
- `ANTIGRAVITY_MASTER_PROMPT.md` — copy/paste prompt for the coordinating Antigravity agent.
- `TEAM_PROMPTS.md` — all four teammate prompts in one file.
- `team_prompts/` — individual prompt files, one per teammate.

## Suggested first steps
1. Put these files in the root of the GitHub repository.
2. Have everyone pull the same latest `main` branch.
3. Have each teammate create their own feature branch.
4. Agree on the API contract before parallel implementation begins.
5. Each teammate runs their individual prompt in Antigravity and commits their own work in small increments.
6. Integrate through pull requests and run the acceptance checklist in `PRD.md`.

The project repository appeared empty when this kit was prepared; inspect it before copying files or generating code in case it has since changed.
